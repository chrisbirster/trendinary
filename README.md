# Trendinary

**The live dictionary of the internet.**

Trendinary is an experimental live internet scoreboard and trend-explanation product. It is currently a visual product prototype using mock trend data.

## Stack

- SolidJS 2 RC
- Solid Router 2 next
- StyleX
- Vite 8
- TypeScript

## Pages

- `/` — Now / live scoreboard
- `/peep` — emerging trends
- `/fomo` — catch-up briefing
- `/following` — personal radar
- `/trend/at-protocol` — trend detail prototype with WTF?, Lore, Vibe, Timeline, and Ask Trendinary

## Run

```bash
npm install
npm run dev
```

Verify:

```bash
npm run verify
```
